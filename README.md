
  # Mental Health Web App

  This is a code bundle for Mental Health Web App. The original project is available at https://www.figma.com/design/0mJ55MHI6nFE48y56N8h98/Mental-Health-Web-App.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
  Lumora – Modern Mental Health Web App

Lumora is a thoughtfully designed mental wellness web application dedicated to supporting personal growth and well-being. Featuring a custom logo and visual identity, Lumora’s frontend was crafted in Figma and developed using Vite, HTML, and CSS, with a focus on clean design, scalability, and responsive layouts for all devices. Built with a modern technical stack and a modular folder structure, Lumora delivers an intuitive user experience, reusable components, subtle animations, and supportive features to help users track and improve their mental health in a welcoming digital environment.
